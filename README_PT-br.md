# Gerenciamento de Consumo de Energia

## 📌 Visão Geral
Este projeto fornece uma estrutura de banco de dados para monitorar o consumo de energia, analisar custos e melhorar a eficiência.

## 📊 Funcionalidades
- Registra o consumo de energia por departamento e ativo.
- Armazena custos relacionados ao uso de eletricidade.
- Sugere dicas para economia de energia.

## 🛠️ Estrutura do Banco de Dados
- `Consumo_Energetico`: Registra o uso de energia por departamento e ativo.
- `Dicas_Economia_Energia`: Contém sugestões para reduzir o consumo.

## 🚀 Como Usar
1. Importe `gerenciamento_consumo_energia.sql` no MySQL.
2. Conecte-o a bancos como `Business_Analytics` e `IT_Asset_Management`.
