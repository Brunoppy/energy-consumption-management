# Energy Consumption Management

## 📌 Overview
This project provides a database structure to monitor energy consumption, analyze costs, and improve efficiency.

## 📊 Features
- Tracks energy consumption per department and asset.
- Records costs associated with electricity use.
- Provides energy-saving recommendations.

## 🛠️ Database Structure
- `Energy_Consumption`: Stores energy usage per department and asset.
- `Energy_Savings_Tips`: Contains suggestions for reducing consumption.

## 🚀 How to Use
1. Import `energy_consumption_management.sql` into MySQL.
2. Connect it with related databases like `Business_Analytics` and `IT_Asset_Management`.
